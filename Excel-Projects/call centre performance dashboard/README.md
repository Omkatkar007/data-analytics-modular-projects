# 📞 Call Centre Performance Dashboard

## 🎯 Overview
An interactive Excel dashboard designed to analyze and evaluate call centre operations, key performance indicators (KPIs), agent productivity, and customer satisfaction.

## 🛠️ Key Metrics & Features
- **Call Volume & Status:** Total calls, answered vs. abandoned call rates.
- **Service Level Metrics:** Average Speed to Answer (ASA), Average Handle Time (AHT), and First Call Resolution (FCR).
- **Agent Performance:** Individual call handling performance, resolution rates, and customer satisfaction ratings (CSAT).
- **Interactive Controls:** Dynamic slicers for filtering by agent, department/topic, date, and resolution status.
- **Excel Capabilities:** Pivot Tables, Pivot Charts, and Advanced Formulas (XLOOKUP, INDEX/MATCH, COUNTIFS, AVERAGEIFS).
